# INTERVIEW_BANK — append-only question/attempt/rubric records (plan §13.1)

One interview question/story is banked per milestone from M1 onward. Store
the FIRST attempt, rubric scores (0–4 per dimension), the correction, and the
delayed retry — never a polished answer alone.

Rubric dimensions (plan §13.2): problem framing · technical correctness ·
evidence/evals · security/reliability · tradeoffs/scope · communication ·
honest ownership.
